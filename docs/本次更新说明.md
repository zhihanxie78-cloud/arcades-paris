# 《拱廊街计划》· Le Livre des passages

本地入口：dist/index.html；独立游戏：dist/game.html；图像画廊：dist/index.html#gallery。

## 2026-11-05 剧情与拼贴版

游戏以玩家和本雅明的思想友谊为基础。十二章围绕一份删改城市声音的虚构画刊展开，包含六十段主线事件、二十四段选择后的人物回应。十五类城市群体都有直接对话：游荡者、拾荒者、收藏家、店员、赌徒、性工作者、丹蒂、看热闹者、工人、密谋者、证券投机者、侦探、三明治人、食利者和诗人。

两种回应都能推进剧情；选择影响当事人的后续台词与调查手札。玩家与本雅明会争论、修正误判、核对证据。角色切换沉思、忧虑和坚定三种透明立绘；玩家的神态与动作随关键回应改变。十二章保留明确的解锁地图，并增加纸页、雨、水光、石色与印刷墨色等转场。场景按日光与暮色区别亮度，采用原创油画与复古纸张界面。

所有剧情、人物姓名及画刊事件均为文学创作。游戏是跨时空蒙太奇，不主张这些人物曾同时与本雅明相遇。语录体台词均注明“依据观点改写”，并关联相应卷轴；不是原著逐字引文。旧 v2 存档保留，可在设置中重新开始以从头阅读新版；旧存档已完成章节可以从地图重温。

导览网站与游戏保持独立。七大部分、三十六卷与五十一篇目录条目、二千二百零七段原始导览材料完整保留。阅读页以手稿、引文纸片、旁注和随文插图组成拼贴，图像使用完整画幅，移除图片和容器的遮罩。日光、暮色、夜间卷轴使用不同纸色与油画背景。

导航、首页与页脚均增加“图像画廊”。一百五十一幅去重图像支持分类、检索、全幅灯箱与回到相应卷轴或档案。AI 插图和角色立绘标注艺术演绎，不能作为历史肖像或建筑史料。

## 背景原作与参考

- J. M. W. Turner，《从安康圣母教堂门廊眺望威尼斯》，约1835，The Metropolitan Museum of Art，Public Domain。用于色彩和笔触背景；画中地点为威尼斯，不作为巴黎实景。https://www.metmuseum.org/art/collection/search/437853
- Camille Pissarro，《冬日清晨的蒙马特大道》，1897，同馆，Public Domain。https://www.metmuseum.org/art/collection/search/437310
- 视觉参考《重返未来：1999》官网的复古舞台与图像编排。页面及角色使用本项目原创素材，不包含该游戏角色、商标或界面截图。https://re1999.bluepoch.com/en/home/
- 设计沿用开源 Taste-skill，按用户要求采用多色莫兰迪油画与纸页拼贴。
