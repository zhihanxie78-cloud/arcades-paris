# 全书结构版

从 dist/index.html 进入，点击“卷轴书库”。沿用夜巴黎视觉与两个专题。

目录依据用户提供的英文版结构，分为译者前言、提纲／大纲、卷轴／笔记汇编、第一批草稿、早期草稿、补遗／预备材料、学术评论与参考附录七部分。

共51个目录入口，其中主体卷轴固定为26个大写字母和10个小写字母（a、b、d、g、i、k、l、m、p、r）。未使用的字母不生成虚构卷轴。

现有2207段导览材料全部保留并重新归类。C、I、J从原先混入的前一卷中拆出，K、M、N子节合并到所属卷轴。旧版数字阅读链接按段落位置映射至新的卷轴链接。

1939年大纲、“拱廊街”预备材料、译者注、人名与术语指南、全书总索引尚缺独立材料，页面明确标注待补。其余已收录内容仍为导览摘录与解读，不代表原著全文或已完成校勘。

每个阅读页面保留主题题图。较长卷轴每约2600字择合适段落间隔插图，正文最多3幅，避免拆开英文摘录与中文解析。图片的题名与艺术演绎标记保留在图注中。

验证：目录数量、字母大小写、C／I／J归属、K／M／N子节、2207段材料无遗漏、全部旧段落链接映射和本地图像引用检查通过。浏览器实际截图验收未完成。
