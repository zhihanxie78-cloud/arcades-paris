# 与本雅明同行 · 发言者与场景版

入口仍为 dist/game.html。导览网站保持独立，游戏使用同一个存档键并兼容旧进度。

## 谁说话，谁出场

对白每次只出现当前发言者的透明立绘。本雅明站右侧，玩家和NPC站左侧；旁白时清空演员。NPC不再作为装框的群体插画出现。

玩家设为32岁的成年男性研究伙伴：深棕头发、浅胡茬、棕灰外套和鼠尾草绿马甲，手持薄笔记本。另为16位具名虚构NPC分别生成独立立绘：马塞尔、莱昂、埃莉丝、杜瓦尔、罗歇、安托万、勒鲁、朱尔、贝尔纳、玛德莱娜、阿尔芒、露易丝、梅尔西耶、巴蒂斯特、勒内、皮埃尔。朱尔的搬运工/工人两种称呼使用同一张图，皮埃尔另用印刷工形象。

所有新图均用内置 imagegen 分别生成，保留真实透明通道；没有以场景画、边框或CSS遮罩代替立绘。原始PNG在 dist/assets/game/cast/，完整提示词见《人物立绘提示词.json》。新主角与NPC是原创虚构人物，人物图不作为历史肖像。

## 每站先说明背景

首次进入与重温章节均先打开独立的场景背景页，再由按钮进入对白。页面交代时间、地点、上一站的具体线索、眼前发生的事件、在场人物、此行要问清的问题与利害。对话过程中可点“本站背景”重新阅读，返回后继续原句。返回地图或重开页面不会丢失进度。

这次也补清了介绍条、赠券、藏家地址、车站约访、画像预约、失物会面、旧校样、诗稿校读、广场递交、印刷作坊与终校之间的因果。跨时空设定与画刊事件仍明确为文学创作。

## 让观点从事情中产生

每章改为：现场事件 → 玩家选择 → 玩家说出选定回应 → 本雅明回答 → 当事人反馈 → 玩家针对刚发生的具体事件追问 → 本雅明解释 → 语录式归纳 → 玩家用自己的话理解并决定下一步。语录手札也保留相应的事件背景与解释，避免单独抽出一句口号。

所有归纳仍注明“观点改写”及关联卷轴，不冒充本雅明原著逐字引文。旧版停在语录节点的存档，会先补读相应解释，再回到语录。
